# 奶娃快跑实现说明

本文描述当前实现；早期选型背景见 [可行性分析](feasibility-analysis.md)。

## 架构与数据流

TypeScript + Three.js + Vite，HTML/CSS HUD。输入由 `Input` 转成统一动作，`Game` 更新状态、运动、碰撞和分数，`World` / `Player` 渲染，`Hud` 按变化更新界面。当前无需业务后端；静态构建可部署到任意静态服务器。

| 模块 | 职责 |
| --- | --- |
| `config.ts` | 车道、速度、动作和道具参数 |
| `rules.ts` | 随机生成、通过条件、速度、计分及难度等级 |
| `Game.ts` | 固定步长、状态、相机、光照与系统编排 |
| `World.ts` | 连续街景、障碍、收集物、生成与回收 |
| `Player.ts` | 程序化 3D 奶娃和动作 |
| `Input.ts` | 键盘与触屏映射 |
| `Sound.ts` | 程序生成音效 |
| `scoreStore.ts` | 本地最高分与静音偏好 |

## 坐标与时间

Y 向上，玩家位于 Z=6，车道中心为 X=-3.2 / 0 / 3.2。距离累计、世界向 +Z 移动。逻辑以 1/60 秒步长运行，帧时间上限 0.05 秒；切后台自动暂停。输入改变目标车道，实际横向位置平滑移动，碰撞使用实际位置。

状态为 ready → running ⇄ paused，撞击后 gameover，可重开。开始、暂停与失败的稳定状态不持续绘制；缩放时补一次绘制。重开清理障碍、收集物和街景，并重置距离、动作、道具及难度。

## 连续街景

13 个 20 米街区按实际距离定位，循环范围 260 米。没有每 20 米重置全部街景的取模逻辑。街区中心落后玩家超过 32 米时才在镜头后回收，并在远方生成新街区。大距离更新可跨多个循环；重开恢复初始街区。

环境随机数由街区编号独立生成，不占用障碍生成随机数。建筑有不同高度、窗框、店面、遮雨棚和屋顶细节，连续道路、人行道和路灯增强距离感。箱体细节按材质做实例化，降低绘制调用；回收释放几何和实例资源。光照采用天空补光、暖色日光、阴影、远景雾和 ACES 色调映射。

## 障碍与难度

每行指定路线最多移动一格。普通行保留无障碍路线；220 米以后，指定路线可能放置可跳 / 可滚障碍，形成动作挑战，但不会连续强制动作行。

| 障碍 | 通过条件 |
| --- | --- |
| 车辆 / 对手 | 换道 |
| 矮路障 | 跳跃高度至少 1.05 或换道 |
| 尖刺 | 跳跃高度至少 1.25 或换道 |
| 货箱 | 跳跃高度至少 1.65 或换道 |
| 横梁 / 闸门 | 地面翻滚或换道 |

基础速度为 `min(28, 14 + distance × 0.012)`，冲刺倍率 1.42。行距随距离从 29–33 米减至 19–23 米。每 300 米提示难度提升，等级上限 4。碰撞窗口与通过条件使用逻辑坐标，不依赖网格形状。

## 成绩、资源与验证

总分为距离取整加星星数 × 10。冲刺 5 秒，磁铁 8 秒，重复拾取刷新持续时间；暂停时计时停止。最高分与静音偏好存储在浏览器本地，没有在线榜单和成绩校验服务。

角色参考和开始页图片的公开分发授权已由所有者确认，见 [素材说明](assets.md)。`npm test` 覆盖规则、世界、角色和声音；街景测试专门验证 20 米边界连续移动、镜头后回收及重开。浏览器脚本验证基本操作和渲染行为，手机视口不等同于真机测试。
