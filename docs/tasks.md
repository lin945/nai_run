## 本地开发

- [x] **T1 工程骨架**：Vite + TypeScript + Three.js、Wrangler 静态资源配置、构建脚本和 Git 忽略；`npm run build` 生成 `dist/`。
- [x] **T2 规则内核**：三道、速度、跳/滚、碰撞与计分配置；可重放随机生成和连续安全道约束；8 项规则与世界测试通过。

- [x] **T4 输入与状态机**：键盘/触屏输入及开始、运行、暂停、失败、重开；后台暂停。

- [x] **T6 UI 与成绩**：开始页、HUD、暂停、结算、重开和本地最高分；桌面和手机视口布局已检查。
- [x] **T7a 本地验证**：`npm test`、`npm run build`、Wrangler dry run、Vite 和 Wrangler 本地服务的桌面/手机视口冒烟检查通过；截图在被忽略的 `log/`。
- [ ] **T7b 真机验证**：Android 与 iPhone 实机帧率、触控、横竖屏和浏览器行为；当前只有 Chrome 手机视口模拟，WebKit 下载未完成。
